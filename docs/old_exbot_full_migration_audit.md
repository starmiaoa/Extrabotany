Rules for this migration:
- Prefer `1.16` behavior when the same feature exists in both old branches.
- Use `master` only for content that is absent from `1.16` or has clearly richer standalone behavior.
- Do not port old Thaumcraft, TConstruct, CraftTweaker, TOP, or WAILA integrations.
- Do not duplicate current modern implementations, especially `void_archives`, `core_of_the_void`, Gaia III, Rainbow/core variants, current flowers, hammers, shields, reward bags, and candy.
- Keep current snake_case registry style for new content; keep existing current IDs unchanged.
